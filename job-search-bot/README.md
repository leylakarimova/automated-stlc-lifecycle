# Telegram-бот для поиска вакансий под ваше CV

Бот сам ищет вакансии на нескольких сайтах, сравнивает каждую с вашим CV
с помощью Claude и присылает в Telegram только подходящие и только с
устраивающей вас зарплатой.

## Как это работает

1. Вы присылаете CV (PDF / DOCX / TXT). Claude кратко описывает ваш профиль
   и придумывает поисковые запросы (их можно поменять через `/queries`).
2. Каждые `CHECK_INTERVAL_HOURS` часов (и по команде `/search`) бот ищет по сайтам:
   - **hh.ru** (Россия, Казахстан, Узбекистан, Азербайджан и др.; регион — `/area`)
   - **remotive.com**: удалённая работа
   - **remoteok.com**: удалённая работа
   - **arbeitnow.com**: Европа / удалённо
3. **Зарплата:**
   - если сайт указал вилку и она ниже ваших ожиданий, вакансия отсеивается сразу,
     без вызова Claude;
   - если вилка указана только в тексте, Claude её находит, и проверка повторяется;
   - валюты и периоды (час/месяц/год) переводятся в вашу валюту в месяц;
   - вилку ниже ожиданий на 10% бот пропускает, потому что верх вилки часто обсуждается;
   - вакансии без зарплаты присылаются с пометкой ⚠️ (отключить: `/nosalary off`).
4. Claude ставит оценку соответствия 0–100 и пишет, почему вы подходите и чего не хватает.
   Присылаются вакансии с оценкой не ниже `/minscore` (по умолчанию 70).
5. Каждая вакансия оценивается один раз и повторно не приходит.

## Запуск

```bash
cd job-search-bot
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env    # и заполните
python -m jobbot
```

Что нужно для `.env`:
- `TELEGRAM_BOT_TOKEN`: создайте бота у [@BotFather](https://t.me/BotFather) командой `/newbot`.
- `ANTHROPIC_API_KEY`: ключ с https://console.anthropic.com.
- `ALLOWED_USER_IDS`: ваш Telegram id (узнать у @userinfobot), чтобы ботом
  не пользовались посторонние за ваш счёт.

Бот должен работать постоянно, чтобы присылать вакансии по расписанию:
на VPS, домашнем сервере или любом хостинге Python (systemd, Docker, Railway, Fly.io и т.п.).

## Команды

| Команда | Что делает |
|---|---|
| `/cv` | загрузить CV (или просто пришлите файл) |
| `/salary 2500 USD` | минимальная зарплата в месяц (`/salary off`: не учитывать) |
| `/nosalary on\|off` | присылать ли вакансии без указанной зарплаты |
| `/queries QA Engineer, Test Automation` | поисковые запросы |
| `/prefs только удалёнка, без gambling` | пожелания, которые Claude учитывает при оценке |
| `/minscore 70` | порог соответствия CV |
| `/remote on\|off` | только удалённая работа |
| `/area 113` | регион hh.ru (113 Россия, 1 Москва, 40 Казахстан, 9 Азербайджан, 0 любой) |
| `/sources` | включить/выключить сайты |
| `/search` | искать прямо сейчас |
| `/settings`, `/pause`, `/resume`, `/reset_seen` | настройки и управление |

## Стоимость

За один прогон Claude оценивает не больше `MAX_VACANCIES_PER_RUN` (40) новых вакансий,
остальные откладываются на следующий прогон. CV кэшируется в запросе (prompt caching),
поэтому за него не платится полная цена при каждой оценке. Модель задаётся в `CLAUDE_MODEL`.

## Как добавить ещё сайт

Создайте класс в `jobbot/sources/` с методом `search(queries, settings) -> list[Vacancy]`
по образцу `remotive.py` и добавьте его в `ALL_SOURCES` в `jobbot/sources/__init__.py`.
Лучше всего подходят сайты с публичным API или RSS. LinkedIn и Indeed запрещают
автоматический сбор данных, поэтому их здесь нет.
